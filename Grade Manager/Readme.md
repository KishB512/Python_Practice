# 🎓 Student Grade Manager (Python CLI Project)

This is a simple **Command Line Python application** to manage student records and their marks.

It allows you to:

- Add students
- Add marks for students
- View student records
- Calculate average marks

This project is perfect for beginners to practice **Python dictionaries, lists, functions, and user input handling**.

---

## 🚀 Features

- ➕ Add new students
- 📝 Add marks for existing students
- 👀 View all student records
- 📊 Calculate average marks per student
- ⚡ Simple CLI-based interaction

---

## 🛠️ Concepts Used

- Python 3
- Dictionaries
- Lists
- Functions
- Loops & Conditionals
