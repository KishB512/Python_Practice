# 🧠 Quiz Answer Finder (Python + JSON)

This Python project fetches quiz data from an online JSON file and allows users to find the **correct answer** by entering a **Question ID**.

It is a great beginner project to learn:

- Working with JSON data
- Fetching data from URLs
- Nested loops
- Dictionary handling
- Searching logic in Python

---

## 🚀 Features

- 🌐 Fetches quiz data from an online JSON source
- 🔍 Searches questions using Question ID
- ✅ Finds and displays the correct answer
- ⚡ Handles nested JSON structures
- 🧠 Beginner-friendly logic

---

## 🛠️ Technologies Used

- Python 3
- `requests` module (to fetch JSON from URL)
- JSON data handling
- Loops & conditionals
