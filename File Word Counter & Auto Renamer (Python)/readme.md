# 📂 File Word Counter & Auto Renamer (Python)

This Python project automatically reads text files from a folder, counts the number of words in each file, and renames the files based on:

- ✅ Word count  
- ✅ Current day of the week  
- ✅ Original filename  

It’s a simple automation script useful for learning **Python file handling, OS operations, and basic automation**.

---

## 🚀 Features

- 📁 Reads all `.txt` files from a directory
- 🧠 Counts total words in each file
- 🗓️ Adds current day name to filename
- ✏️ Renames files automatically
- ⚡ Simple and beginner-friendly code

---

## 🛠️ Technologies Used

- Python 3
- `os` module (file handling)
- `datetime` module (date formatting)
